# Pesquisa e integrações

Para cada ensaio, registre hipótese, revisão do código e da amostra, critério de aceite, resultado e limitações. Para medir uso de memória, registre o pico de RSS, o comando e a versão do ambiente. Use evidências sintéticas nas publicações.

| Frente | Integração conceitual |
| --- | --- |
| CERBERUS | Usar o ciclo de validação, ativação e restauração como referência ao modelar decisões de política. |
| ÍCARUS | Medir tempo de execução e pico de memória para comparar variantes do mesmo ensaio. |
| Centurião | Organizar uma revisão operacional com critérios para triagem e encerramento. |
| Ruby Orion | Explorar um leitor independente para conferir a integridade das evidências exportadas. |
| Argus | Avaliar a normalização de texto sintético antes da análise, preservando a referência ao registro original. |
| Pulse | Prototipar uma visualização de contagens e alertas a partir de resumos exportados. |
