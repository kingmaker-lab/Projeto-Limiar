# Projeto Limiar

Laboratório de pesquisa em computação, arquitetura, criptografia experimental e inteligência semântica.

| Frente | Onde começar |
| --- | --- |
| **Cerberus Fase II** | [Serviço local de controle de configuração](cerberus/phase-ii/README.md), com CLI, testes e modelos executáveis. |
| **Ouroboros Fase II · O Limiar da Serpente** | [Laboratório experimental](ouroboros/phase2/README.md), com referência Feistel de 16 bits, dados sintéticos e plano de reprodução. |
| **JANUS · Beyond Language** | [Documentação e roadmap](janus/README.md) para investigar representação semântica, interpretação contextual e inferência a partir do Argus v0.4. [Ver no portal](https://workshop-limiar.wolfpackworkshop.workers.dev/#janus). |
| **Protocolos de pesquisa** | [Índice de publicações](pesquisa/README.md) de ICARUS, ATHENA, GAUSS, ATLAS e OMEGA. |
